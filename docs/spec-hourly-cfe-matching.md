# 功能規劃：逐時（24/7 CFE）時間匹配機制

- **狀態**：規劃中（對應 Roadmap 新增卡 `A9` / `B7` / `C6`，Phase 6；不依賴真實 AMI，可提前啟動）
- **日期**：2026-07-28
- **一句話**：只有「同一小時內，風電發電與用電同時發生」的重疊部分，才算真綠電匹配。

---

## 1. 目標與定義

業界稱 **24/7 CFE（Carbon-Free Energy）／時間匹配**。與「月/年總量淨額」不同：**發電時沒人用（外溢）不算、用電時沒風（缺口）也不算**。

對每個小時 `h`（一天 24 點）：

- `匹配(h) = min(風電發電(h), 用電(h))` ← 重疊部分
- `外溢(h) = max(0, 發電−用電)`（發了沒人用，浪費）
- `缺口(h) = max(0, 用電−發電)`（要用沒風 → 買灰電）
- **CFE%（逐時匹配率）= Σₕ 匹配(h) / Σₕ 用電(h)**

CFE% 會**低於帳面 RE%（月總量）**，兩者差距就是「對不上時間」的部分——這正是平台要凸顯的核心洞見。

## 2. 已定決策

| 項目 | 決定 |
|---|---|
| 時間解析度 | **逐小時 24 點**（24/7 CFE 標準） |
| 資料來源 | **先用典型曲線建模**（現在就能做）；之後接真實 15 分鐘資料替換（Roadmap `A4`） |
| 匹配範圍 | **多案場 × 多客戶，逐時最佳配置** |
| 餘電/儲能 | **嚴格時間重疊、不跨區間**（純匹配）；儲能跨區間為 `B5` 疊加，不在本功能 |

## 3. 與現況的關係（不重造輪子）

平台**已在 3 個時間電價時段（尖峰/半尖峰/離峰）做「重疊才算」的匹配**（`slot_optimizer` / `slot_matching_service`，含「時段錯配外溢」），這是本功能的雛形。**本功能＝把顆粒度從 3 段細化到 24 小時、並正式化為 CFE 指標**。3 時段結果保留為對照；逐時為主。

## 4. 資料層：逐時曲線建模器（`A9`）

把現有的月/時段資料，用典型曲線 shape 成 24 點：

- **風電**：季節 × 典型日型（沿用現有 `_WIND_PROFILE` 月係數 + 一條風電日內曲線，夜強日弱）。
- **用電**：依**產業別**典型負載日型（半導體 24h 高基載、面板/電子日尖峰、辦公室白天型…）。
- **對帳保證**：`Σ 逐時 = 原月/時段量`（不憑空增減，可稽核）。
- **明確標示「建模（半模擬）」**；之後 `A4` 真實 interval 進來即可**原地替換**，引擎與指標不動。

## 5. 引擎：逐時匹配（`B7`）

純函數、確定性、可稽核（延續現有引擎風格）。對每小時 `h`：

- 供給：各案場 `gen(f,h)`（受合約上限／佔比、案場發電）
- 需求：各客戶 `load(c,h)`
- **每小時做一次分配**（比照現有 slot 引擎的 min-based / 小型 MILP），只計重疊、**不跨小時**（外溢就是外溢）
- 產出：`matched(c,f,h)`、`surplus(f,h)`、`shortfall(c,h)`

> 合約上限的「月量」需先按逐時配比分攤（可沿用 `contract_terms` 的月別配比概念，延伸到小時）。

## 6. 指標與 API

- `CFE%(c) = Σₕ matched(c,h) / Σₕ load(c,h)`；另給逐案場利用、外溢總量、缺口總量。
- **對比**：帳面 RE%（月總量）vs 逐時 CFE% → 差距即時間錯配。
- 端點（初版）：`GET /matching/hourly?customer_id=&period=` → 逐時序列 + CFE 彙總；或整合進 `customer-optimization`。

## 7. 前端：逐時匹配視圖（`C6`）

- **24 小時曲線**（發電 / 用電 / 已匹配 / 外溢 / 缺口）——與產品介紹頁的「破題圖」同語言，但**真的用這家客戶的建模資料**。
- **CFE% 讀數** + 帳面 RE% 對比。
- **時 × 日熱力圖**（哪些時段長期匹配不足）。
- 整合進**售電評估**，或新增「逐時匹配」分頁。
- 明確標示「逐時為建模（半模擬）；接真實資料後更新」。

## 8. 階段與驗收

| 步驟 | 內容 | 驗收 |
|---|---|---|
| 1（後端） | 建模器 `A9` + 逐時引擎 `B7` + CFE 指標/API | `Σ逐時 = 原量`；`CFE% ≤ 帳面 RE%`；多對多每小時分配正確、不跨區間；純函數/確定性 |
| 2（前端） | 逐時視圖 `C6`（曲線 + CFE + 熱力圖） | 一眼看出時間錯配；標示建模 |
| 3（升級） | 接真實 15 分鐘資料（`A4`）替換建模；即 `B6` | 引擎/指標不動，資料換真；可與台電對帳 |

## 9. 未來延伸
